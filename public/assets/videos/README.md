# 動画アセットの置き場所

このフォルダに本番の mp4 を配置すると、自動でプレースホルダ演出から実動画に切り替わります。
ファイル名は `src/config/manifest.ts` の設定と一致させてください。

## 演出動画（2種類） → `staging/`

| 種別       | ファイル名（manifest.staging） | 再生されるタイミング                     |
| ---------- | ------------------------------ | ---------------------------------------- |
| 通常演出   | `staging_normal.mp4`           | レア度が `staging: "normal"` のとき       |
| 当たり演出 | `staging_hit.mp4`              | レア度が `staging: "hit"` のとき（SR/SSR）|

## 排出動画（ラインナップの数だけ） → `drops/`

`manifest.items` の各 `dropVideo` に対応。現在の設定では以下:

| アイテム     | レア度 | ファイル名        |
| ------------ | ------ | ----------------- |
| 竹ボウキ     | N      | `takebouki.mp4`   |
| 竹とんぼ     | N      | `taketombo.mp4`   |
| タケノコ     | R      | `takenoko.mp4`    |
| タケコプター | SR     | `takecopter.mp4`  |
| 武井壮       | SSR    | `takeishou.mp4`   |

## 補足

- 対応形式は基本 mp4（H.264/AAC 推奨）。ファイルが無い/読み込めない場合は
  canvas のプレースホルダ演出に自動フォールバックします。
- 動画は自動再生の制約回避のため既定でミュート再生します。音声を鳴らす必要が
  あれば `src/ui/videoStage.ts` の `this.video.muted` を見直してください
  （ユーザー操作起点の再生なので音声ありでも動くことが多いです）。
- ラインナップを増減したいときは `manifest.items` を編集し、対応する mp4 を
  `drops/` に追加してください。
